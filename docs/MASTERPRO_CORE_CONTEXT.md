Нулевой контекст платформы MasterPro

1. О чём проект

MasterPro — это мобильная платформа сервисных и инженерных услуг.

Платформа объединяет:

- клиентов
- мастеров
- партнёрские магазины
- индустриальные объекты
- сервисные компании
- поставщиков материалов

MasterPro — это не просто каталог мастеров и не просто маркетплейс.

Это сервисно-инженерная платформа, где соединяются:

- создание заявок
- вызов мастеров
- инженерное проектирование
- расчёт смет
- закуп материалов
- обслуживание объектов
- партнёрские и индустриальные сценарии

---

2. Главная идея платформы

Пользователь в MasterPro заходит не в список мастеров, а в систему действий.

Логика платформы:

пользователь выбирает действие → система подбирает нужный сервис → включаются нужные движки

Это ключевое отличие MasterPro от обычных досок объявлений.

---

3. Главные пользовательские роли

Client — клиент платформы
Master — исполнитель работ
Shop Partner — партнёр магазина
Industrial Partner — индустриальный партнёр

Каждая роль имеет собственный режим интерфейса.

---

4. Основные режимы интерфейса

После входа пользователь работает в режиме:

- Client
- Master
- Shop Partner
- Industrial Partner

Режим определяет:

- доступные функции
- кабинеты
- сценарии использования

---

5. Основные модули платформы

MasterPro строится как модульная система.

Основные модули:

- Client Module
- Master Module
- Marketplace Module
- Shop Module
- Project Editor Module
- Calculation Module
- Dispatch Module
- Object Passport Module
- Jobs Module
- Industrial Projects Module

Каждый модуль должен быть независимым.

---

6. Архитектура интерфейса

Навигация платформы имеет двухуровневую модель.

Уровень 1 — Платформа

SplashScreen → HomeScreen

HomeScreen — центр действий.

Уровень 2 — Разделы платформы

- Услуги
- Экстренный мастер
- Сметмастер
- Индустриальные
- Обслуживание
- Вакансии
- Мои заявки
- Магазин

---

7. Геолокация

Платформа имеет общий географический слой.

Карта используется для:

- поиска мастеров
- экстренных вызовов
- магазинов
- вакансий
- маршрутов

---

8. Экстренный мастер

Экстренный мастер — отдельный режим работы мастера.

У мастера есть состояния:

- на линии
- экстренный режим

Экстренная заявка отправляется только мастерам:

- на линии
- с включенным режимом экстренного мастера

Система может учитывать:

- срочность
- время суток
- дисциплину мастера
- фактическое время прибытия

---

9. Магазины

Магазины являются партнёрским модулем платформы.

Партнёры могут:

- создавать витрину товаров
- публиковать цены
- обновлять ассортимент

Магазины отображаются на карте.

---

10. Роль магазинов

Магазины являются источником цен материалов.

Цепочка работы:

магазин → каталог товаров → цены → SmetMaster

---

11. Вакансии

Модуль вакансий показывает:

- минимальную зарплату
- среднюю зарплату
- максимальную зарплату

Это превращает вакансии в аналитический инструмент.

---

12. Логика создания заказа

Цепочка создания заказа:

User → ChatMaster → orderDraft → SmetMaster → Dispatch

---

13. ChatMaster

ChatMaster преобразует человеческий запрос в структуру работ.

Он должен понимать:

- разговорный язык
- ошибки
- неполные запросы

---

14. orderDraft

orderDraft — центральный объект заказа.

Он хранит:

- список работ
- количество
- стоимость
- адрес
- параметры

---

15. SmetMaster

SmetMaster — расчётное ядро платформы.

Он выполняет:

- расчёт работ
- расчёт объёмов
- расчёт стоимости
- расчёт материалов

---

16. Project Editor

Project Editor — инженерный редактор.

Он предоставляет:

- геометрию помещений
- поверхности
- точки
- маршруты

SmetMaster использует данные проекта.

---

17. Индустриальные

Раздел коммерческих объектов называется:

Индустриальные

Он используется для B2B проектов.

---

18. Кабинеты

В системе существуют кабинеты:

Master Cabinet
Shop Cabinet
Industrial Cabinet

---

19. Рейтинг

Рейтинг влияет на:

- доверие клиента
- доступ к заказам
- участие в индустриальных проектах

20. Тарифная система

Тариф определяет доступ к функциям.

Comfort — доступ к расширенному SmetMaster.

Comfort+ / Premium — доступ к закупке материалов через магазины.
